# Levantamento de Requisitos — TechPro


## Escopo geral do projeto

1. Para cada etapa do fluxo do protótipo (Contato / Proposta / Suporte / Visita técnica / Instalação), quais informações precisam ficar registradas e consultáveis depois?
Por exemplo:

- **Contato:** dados do cliente, canal de origem
- **Proposta:** valor, itens/serviços, status
- **Visita técnica:** data, técnico responsável, resultado da vistoria
- **Instalação:** data, equipe responsável, status de conclusão
- **Suporte/manutenção:** motivo do chamado, status, histórico

  Alguma etapa não precisa virar registro no sistema? Falta alguma etapa ou dado importante que não aparece nesse fluxo?

2. Qual o tamanho da empresa hoje (número de funcionários)? Qual seria a estimativa de usuários internos com acesso ao sistema?

## Processo de atendimento atual

3. Como funciona hoje o recebimento de pedidos de orçamento? É só pelo WhatsApp? Quais dados o cliente costuma informar neste primeiro contato?

4. No fluxo completo, do primeiro contato até a instalação concluída, qual etapa costuma ser a mais demorada ou mais difícil de gerenciar?

5. Se pudessem escolher UMA funcionalidade para resolver o maior problema do dia a dia, qual seria?

6. Como é organizado o controle de clientes hoje (planilha, papel, WhatsApp Business)? Quais dados de cadastro do cliente são considerados obrigatórios (ex: nome, endereço, tipo de imóvel, histórico de serviços)? Essa organização precisa ser replicada no novo sistema?

7. Como é definido e acompanhado o cronograma de visitas técnicas e instalações? Existe algum tipo de agenda compartilhada?

8. Quais são os possíveis status de um pedido/chamado ao longo do processo? (ex: novo, em orçamento, aprovado, agendado, instalado, em manutenção). Quem pode mudar cada status?
